# Task Tracker
This is just a fun prject that I am working on to learn and understand more about coding and data structures.

## About the project
So I am making a simple task tracker in python where you can add, update and save your tasks in terminal. It includes features like -
1. Adding a task
2. Updating a task
3. Marking a task as "Done" and "In progress"
4. Listing all tasks

Each task has it's unique id that differentiates it from other task, a description, status and time when the task was created and when it was updated last.
